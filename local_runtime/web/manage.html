2. 在新机器导入

恢复前会自动备份目标机器的 data、materials、config。当前机器已有的 API Key 和配置保留，模型/维度不匹配会拒绝恢复。准备恢复后暂停写入，请在终端停止服务并重新执行启动命令。重新进入时需选择用户。

命令行也可使用：bash migrate.sh export ／ bash migrate.sh inspect 文件.tar.gz ／ bash migrate.sh restore 文件.tar.gz。命令行导出与恢复前需要停服。
