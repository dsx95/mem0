# 记忆模块产品化评估（2026-09-26 更新）

范围：本仓库的 local_runtime 网页、聊天、资料导入、日记及可选重排序。结论来自代码检查和本地测试，
不是生产压测、渗透测试或真实模型质量认证。现阶段适合单所有者本机/受信任私有环境试用。

P0：面向多个真实用户或接入设备动作前完成。P1：小规模正式运营前完成。P2：按规模与测量结果推进。

## 建议实施顺序

1. 先确定部署场景。单家庭本机可继续 SQLite；开放给互不信任的多用户前先补真实登录与关系退出流程、完整删除隐私策略、备份恢复。
2. 事实主表/冲突版本与 outbox 已实现，接着做真实语义评测、别名归一化和统一任务调度；若接机器人，同时做结构化空间状态和动作约束。
3. 建真实评测集、性能/费用指标，再决定 Rerank 参数、增量日记、缓存、PostgreSQL 和 Qdrant Server 的投入。

Redis 不是产品化的前提，也不能替代事实数据库、权限校验或备份。SQLite 是持久数据库；何时迁移应由并发写入、
多实例部署和恢复要求决定。相关原理见 [SQLite 适用场景](https://www.sqlite.org/whentouse.html)。
本仓库使用 qdrant-client Local Mode，不是 Qdrant Server 或 Qdrant Edge；扩展部署方式参见
[Qdrant Client 官方说明](https://github.com/qdrant/qdrant-client)。

对象授权检查参见 [OWASP API1](https://api-security.owasp.org/editions/2023/en/0xa1-broken-object-level-authorization/)。
Rerank 协议与输入预算参见 [百炼官方接口](https://help.aliyun.com/zh/model-studio/text-rerank-api)。
